Quick Blog – MERN Stack Blogging Application

1. Project Overview

Quick Blog is a full-stack blogging web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).It allows users to create, read, update, and delete blog posts through a clean and responsive user interface.
This project demonstrates full-stack development skills including frontend development, backend API creation, database management, and REST API integration.

2. Tech Stack Used

Frontend:
React.js
Axios
React Router DOM
CSS / Bootstrap / Tailwind

Backend:
Node.js
Express.js

3. Features
Create new blog posts
Read all blog posts
Update existing blog posts
Delete blog posts
View single blog details
RESTful API integration
Responsive design
Fast and smooth user experience
